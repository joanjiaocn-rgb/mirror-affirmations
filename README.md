# Mirror Affirmations

Working name: Mirror Affirmations

This folder contains the v0 product package for a private mirror affirmation web demo and waitlist site.

## Documents

- `docs/prd-v0.md` - product definition, MVP scope, risks, and acceptance criteria.
- `docs/page-matrix.md` - SEO route plan and page content requirements.
- `docs/web-demo-contract.md` - interaction, data, privacy, and analytics contract for the browser demo.
- `docs/validation-plan.md` - 14-day validation plan before building the full mobile app.
- `docs/seo-copy-freeze.md` - frozen English landing and SEO page copy for design/frontend.
- `docs/visual-design-source.md` - visual direction, layout, components, and frontend handoff.
- `docs/copy-design-handoff.md` - short handoff summary for the implementation stage.
- `data/prompt-library-v0.json` - first structured prompt library for the demo.

## Current Recommendation

Build the website and web demo first. Do not build the full native app, subscriptions, cloud sync, account system, or AI emotional summaries until the demo proves that users are willing to open the camera, practice with the prompt, and join the waitlist.
