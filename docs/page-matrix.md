Date: 2026-07-30
Target market: US / English

## Page Strategy

The site should not be a generic landing page only. Each indexable page should answer a specific self-care search intent, give users sample lines they can try immediately, then route them into the private web demo.

## Homepage Requirements

Title:

Mirror Affirmations | Private Self-Talk Practice

Meta description:

Open a private mirror practice, read gentle affirmations on screen, and try positive self-talk with your own face and voice. No recording in the web demo.

Hero message:

- H1: Mirror Affirmations
- Subheading: A private mirror practice for saying one gentle thing to yourself.
- Primary CTA: Start private practice
- Secondary CTA: Join the waitlist

Above the fold must show the product, not a marketing-only hero. The first viewport should include a phone-like demo preview or live demo entry.

## SEO Content Formula

Each SEO page should include:

- Direct answer: what this practice is and who it is for.
- 5-10 sample affirmations in first-person language.
- A short step-by-step practice.
- Privacy note: camera stays local in the browser demo.
- When not to use it: not a replacement for therapy or emergency help.
- FAQ with 3-5 questions.
- Internal links to `/demo`, `/bedtime-affirmations`, `/positive-self-talk`, and `/privacy`.

## First Content Briefs

### `/mirror-affirmations`

Search intent: users want to understand mirror work or try affirmations in front of a mirror.

Angle: make it private, short, and non-cringe.

Must include:

- Definition of mirror affirmations.
- Difference from reading quotes.
- 60-second practice.
- 8 sample prompts.
- Privacy explanation.

### `/selfie-affirmations`

Search intent: users want a camera-based, personal affirmation experience.

Angle: selfie mode as a modern private mirror, not a public selfie post.

Must include:

- Explain that the web demo uses the camera only for preview.
- Mention no recording in web demo.
- 8 sample prompts for camera practice.
- CTA to `/demo`.

### `/video-affirmations`

Search intent: users want to record or create affirmation videos.

Angle: validate interest in future app recording, but do not promise current recording in web demo.

Must include:

- Explain difference between practice mode and future app recording.
- Waitlist CTA for local-only recording.
- Privacy-first positioning.

### `/bedtime-affirmations`

Search intent: users want calming bedtime affirmations.

Angle: one gentle line before sleep.

Must include:

- 10 bedtime prompts.
- Simple 3-step routine.
- Avoid medical sleep claims.
- Link to `/demo`.

### `/positive-self-talk`

Search intent: users want a practical self-talk exercise.

Angle: turn affirmations from abstract words into a spoken mirror practice.

Must include:

- Explain positive self-talk without overclaiming.
- 5 low-pressure scripts.
- CTA to practice privately.

## Internal Linking Rules

- Homepage links to all main SEO pages and `/demo`.
- Every SEO page links to `/demo` in the first half of the page.
- Every page links to `/privacy` near the demo CTA.
- `/video-affirmations` should link to waitlist, not imply recording is available.
- Use natural anchor text, not repeated exact-match anchors.

## Content Guardrails

Do not use these claims:

- Cure anxiety.
- Treat depression.
- Heal trauma.
- Diagnose mood.
- Read your face.
- Detect emotion.

Use these phrases:

- Private self-care practice.
- Positive self-talk.
- Gentle reflection.
- Emotional check-in.
- Mirror practice.
- Not a medical or therapy service.
